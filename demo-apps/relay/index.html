How it works

From zero to paged in under five minutes

No agents, no sidecars, no YAML archaeology. Drop the SDK into your service and Relay starts learning what "normal" looks like.

01

Install the SDK

One package, zero config files. Works with Node.js today; Python and Go SDKs are in beta.

$ npm install @relay/sdk
02

Wire up your services

Initialize once per service. Relay auto-discovers your routes and starts tracking latency, error rates, and throughput per endpoint.

Relay.init({ token: process.env.RELAY_TOKEN })
03

Get paged when it matters

Anomaly detection tuned per endpoint — not one global threshold. Alerts route to Slack, PagerDuty, or plain webhooks.

✓ alert → #incidents · @on-call
